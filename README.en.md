# DSH Motion UI

[简体中文](README.md) | English

Turn [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) responses into **interactive interfaces, diagrams and animations** when useful: from comparisons, quizzes and parameter calculators to HTML/SVG canvases, mechanical illustrations and local video production. The model can still answer in ordinary text; interface generation depends on the task, model and settings.

## What can it do?

| Use case | Capabilities |
| --- | --- |
| Everyday explanations | Cards, comparisons, flows, timelines, code, formulas and tabs |
| Data exploration | Table filtering / sorting, CSV export, charts and adjustable parameters |
| Learning and input | Local quizzes, forms, function plots and structural diagrams |
| Freeform expression | Model-authored HTML/SVG, animations, basic 3D and interactive canvases |
| Mechanical illustrations | Adjustable assembly, gear and crank-linkage demonstrations |
| Video production | Motion timelines, storyboard previews, MP4 export, editing, and optional voice and captions |

Interfaces appear in the response and the **Smart UI** sidebar. Compatible parameters and some view state can be saved, and the model can later edit an existing interface. Controls respond locally; parameters are sent to the Agent only when a follow-up is explicitly submitted.

## Compatibility and installation

- Supports DSH **Web / Desktop**. The current repository explicitly declares compatibility with `0.2.0-rc.2`, `0.2.1-rc.1`, `0.2.1-rc.2`, `0.2.1-rc.3`, `0.2.1-rc.4` and `0.2.1-rc.5`; see [package.json](package.json).
- Requires Node.js `>=22.19`. Everyday interfaces do not require the video toolchain; see video requirements below.

For Desktop, install its `dsh` command through **Application → Manage dsh Command** first:

```sh
dsh plugin --profile desktop add dsh-motion-ui
```

Replace `desktop` with `web` for Web. Restart DSH after installation; Web users should also reload the browser page. Settings are under **Plugins → Installed → dsh-motion-ui**. You can also install it through the [Enhancement Suite](https://github.com/Scorp1o117/dsh-enhancement-suite).

If the development plugin `dsh-generative-ui` is installed, remove it before installing Motion UI. They register the same tools and should not run together. Older interface documents remain readable, but settings must be selected again under the new plugin entry.

## Quick start

Ask for a task that benefits from a visual, for example:

- “Explain voltage, current and power with adjustable parameters.”
- “Compare these two options and let me adjust the budget.”
- “Make a local quiz with answer explanations.”
- “Animate a gear drive with speed and pause controls.”

In plugin settings, choose **Guided** or **Free** mode. Guided mode supplies design guidance, style and examples; Free mode leaves the design to the model without injecting those styles and examples. Whether the model invokes tools, as well as interface quality and correctness, depends on the model and request.

## Tools and behavior

| Tool | Purpose |
| --- | --- |
| `render_text` / `render_scene` | Quick typography or common flow, comparison, allocation and budget scenes |
| `render_ui` | Validated native components, charts, quizzes and forms |
| `render_canvas` | Freeform HTML / SVG canvases and animation |
| `render_mechanism` | Assembly, gear and crank-linkage illustrations |
| `ui_catalog` | Retrieve protocol, fields and examples on demand |
| `inspect_ui` / `update_ui` / `patch_ui` | Inspect and continue editing an existing interface |

Completed content can appear progressively during generation. Full interaction starts after a successful result and state restoration. Some PTC / composite tool paths may show the text fallback instead. Removing the plugin does not automatically delete locally saved interface state.

## Video production

When explicitly asked to make a video, the model can preview a timeline, render MP4, inspect a video or join clips, and deliver editable source and project files. Install **Chrome / Edge or Playwright Chromium, FFmpeg and FFprobe** locally first; the plugin does not download a browser or encoders automatically. The plugin settings can check the video environment.

Optional voice synthesis uses MiniMax, requires separate authentication and may incur API charges. Silent motion videos work without it. Ordinary conversations are not automatically exported as video. Frame sampling checks only selected moments; it is not a complete visual, audio or content review.

## Limits and safety

- The correctness of charts, calculations and illustrations depends on supplied data, model output and implementation. Verify results for professional use.
- Freeform canvases run in an isolated iframe with restrictions on host-page and network access. Isolation does not provide hard CPU or memory limits; complex or problematic code can still affect responsiveness.
- Do not supply unrelated credentials or private data to generated canvases. External services, models and assets have their own terms.
- This project does not claim to implement ChatGPT's proprietary UI protocol or compiler.
